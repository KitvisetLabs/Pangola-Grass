# Kitviset Pangola — multilingual static site

The source repository is public. The GitHub Pages site is at https://kitvisetlabs.github.io/Pangola-Grass/. At the latest public check, the root page, Thai page, stylesheet and all 16 archive images on the Thai page were reachable. Search indexing has not been checked.

The repository contains 109 HTML pages across nine languages. Locale hubs use `/{locale}/home.html`; the hay-quote checklist remains at the legacy `/{locale}/` route. The eight non-Thai language versions are draft translations awaiting native-speaker review; consult the Thai source.

Business archive pictures appear only in the products galleries and do not represent current stock. Shop and field are separate locations; call 093-069-8712 to confirm the collection location and time before travelling.

The project-folder robots.txt is a reference file, not the origin-level robots policy. No scripts, trackers, forms or dependencies are required to read the static HTML pages.
